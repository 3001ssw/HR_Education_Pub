# 유아 학습지 (A4 인쇄용)

집에서 A4로 인쇄해 쓰는 유아 학습·놀이 학습지 모음입니다.
모든 학습지는 HTML 파일이며, 브라우저로 열어 인쇄하면 장마다 A4 한 장에 맞게 나옵니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| [`hangul/`](hangul/) | 한글 — 선 긋기, 자음·모음, 글자·낱말 따라쓰기 |
| [`math/`](math/) | 수학 — 숫자 쓰기, 수 세기, 모양·패턴, 간단한 더하기 |
| [`english/`](english/) | 영어 — 알파벳 따라쓰기, 쉬운 단어 |
| [`play/`](play/) | 놀이 — 미로, 색칠, 점 잇기, 같은 그림 찾기 |

## 인쇄 방법

1. HTML 파일을 내려받아 브라우저(크롬·엣지 등)로 엽니다.
2. 위쪽 「🖨️ 인쇄하기」 버튼 또는 Ctrl+P를 누릅니다.
3. 용지 **A4**, 배율 **100%**(실제 크기), **배경 그래픽 켜기**로 인쇄합니다.
4. 필요한 장만 골라 인쇄해도 됩니다.
